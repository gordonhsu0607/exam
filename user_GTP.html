檔案格式

欄位是否必填說明
題型選填填「單選」或「複選」。留空時依正確答案的個數自動判斷。也接受欄名 類型、單複選、type。
題目必填題目內容。也接受欄名 試題、考題、問題、題幹、question。
選項A ～ 選項H至少 2 欄也接受欄名 A、B、C…、A選項、選項1～選項8、option1。留空的選項欄會忽略,所以各題選項數可以不同。
正確答案必填可用字母 B、A,C、ACD、(B),或用數字 2、1,3。也接受欄名 答案、標準答案、正解、answer、key。
固定選項選填要固定在最後一個、不參與隨機的選項字母，例如 D 或 C,D。也接受欄名 固定最後、末位選項、pin。

標題列不必在第一列(會往下找 30 列),也不必是第一個工作表(會掃過所有工作表)。欄位順序不限,多餘欄位會忽略。

預覽

名冊內嵌在這個 HTML 檔裡,拿到檔案的人用文字編輯器就能看到內容。因此本檔只存遮罩後的姓名(徐X睿),不存完整姓名;完整姓名請保留在你自己的 Excel 內。

Google 表單欄位對應

不用自己找 entry 編號。照下面三步做,貼一條連結就會自動對應好。
  1. 在 Google 表單裡,每個要收的資料開一題「簡答」,並把每題設為非必填
  2. 在該題的答案框裡填入下表的關鍵字(例如「姓名」那題就填 name),然後右上角「⋮ → 取得預先填入的連結」→ 取得連結 → 複製
  3. 把連結貼到下面的框裡,按「解析連結」
表單設定要檢查兩項,否則外部人員送不進來:「設定 → 回覆」裡的「收集電子郵件地址」要關閉;若表單屬於公司帳號,「限制為 ASUS 使用者」也要關閉。

Google Apps Script 接收端

  1. 開一份新的 Google Sheet(在瀏覽器輸入 sheets.new)
  2. 選單「擴充功能 → Apps Script」
  3. 把原有內容刪掉,貼上下面整段程式碼,存檔
  4. 右上「部署 → 新增部署作業」,類型選網頁應用程式,執行身分我,具有存取權的使用者任何人
  5. 複製結尾是 /exec 的網址,填進上面的「接收端網址」,按「儲存設定」再按「送測試資料」

發佈 / 備份

          
你在後台做的所有修改(測驗、題庫、名冊、回傳設定、密碼)目前只存在這台瀏覽器。要讓別人拿到同樣的內容,請匯出新的 HTML 檔,再上傳到雲端空間覆蓋舊檔。

          

            
產出考試用檔案

            

              
              
            

            
考試版完全沒有後台、也不含管理密碼,是要放到雲端空間給人考的那一份。管理版含完整後台,自己留在電腦裡改題目用 —— 不要上傳管理版。

            
離線 / 單機使用也是同一個檔案：把「回傳設定」選成「不回傳」再匯出考試版，雙擊打開就能考，成績用回報碼收卷。不需要另外一份單機版檔案。

            

              
              
            

            

              
            

          

          

            
可以放在哪些雲端空間

            
要能當「網頁」打開才行。可用:GitHub Pages、Cloudflare Pages、Netlify、Azure 儲存體靜態網站、AWS S3 + CloudFront、公司自己的網站空間。

            
不能用:Google Drive、OneDrive、Dropbox 的分享連結 —— 這些只會讓人下載檔案,不會把 HTML 當網頁執行。

            
上傳時建議把檔名改成 index.html,網址才會乾淨。換新版只要覆蓋同一個檔案,考試連結不用改。

這個版本的限制

            
    
              
  • 評分在瀏覽器端完成,正確答案存在考試版檔案裡(有做編碼、畫面不顯示),懂開發者工具的人有可能反推。不適合升等考等高風險考試。
    • 
              
  • 「只能作答一次」只能擋同一台瀏覽器;換瀏覽器或無痕視窗可以再考。要真正擋住需要伺服器端判斷。
    • 
              
  • 回傳網址與共用密鑰也在檔案裡。密鑰只能防止亂送,不能當成身分驗證。
    • 
              
  • 接收端(Google Sheet / Power Automate)要確定允許外部寫入,否則成績只會留在佇列裡。
